# SDD Model Guide

Recommended model tier per SDD command. SDD Full uses the `/speckit.*`
pipeline; SDD Lite uses `/specification` and `/implementing` from
`vtex/vtex-agent-skills`.

| Command | Tier | Reference model |
|---|---|---|
| `/speckit.constitution` | Tier 1 reasoning | Claude 4.7 Opus or higher |
| `/speckit.specify` | Tier 1 reasoning | Claude 4.7 Opus or higher |
| `/speckit.plan` | Tier 1 reasoning | Claude 4.7 Opus or higher |
| `/specification` | Tier 1 reasoning | Claude 4.7 Opus or higher |
| `/implementing` | Tier 1 reasoning | Claude 4.7 Opus or higher |
| `/speckit.clarify` | Standard execution | Claude 4.6 Sonnet or higher |
| `/speckit.tasks` | Standard execution | Claude 4.6 Sonnet or higher |
| `/speckit.analyze` | Standard execution | Claude 4.6 Sonnet or higher |
| `/speckit.implement` | Standard execution | Claude 4.6 Sonnet or higher |

## SDD Full vs SDD Lite (per task)

Use **SDD Full** when ANY of:

- estimated effort > 5 days
- high ambiguity in requirements
- cross-team dependencies
- significant architectural impact
- involvement in critical flows

Otherwise use **SDD Lite** (`/specification` + `/implementing`).

| Artifact | SDD Full | SDD Lite |
|---|---|---|
| `.specify/memory/constitution.md` | required | not used |
| `docs/scope_of_work/<feature>.md` | required (input to `/speckit.specify`) | not used |
| `specs/<feature>/spec.md` | generated | — |
| `specs/<feature>/plan.md` | generated | — |
| `specs/<feature>/tasks.md` | generated | — |
| `specs/<feature>/analysis.md` | generated | — |
| `specs/<feature-name>.md` | — | generated by `/specification` |

For this repository both modes are wired:

- `make sdd-init` scaffolds `.specify/` (run once per repo).
- The SDD Lite skills live under `.agents/vtex-skills/` (in-repo install).
